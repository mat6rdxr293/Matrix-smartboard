# Backend

FastAPI хранит школьные аккаунты, кабинеты, уроки, операции доски и чат с ИИ в SQLite.

## Настройка

Скопируйте `.env.example` в `.env`. Основные параметры:

- `AI_BASE_URL` — адрес OpenAI-compatible API локальной модели; для Ollama: `http://localhost:11434/v1`;
- `AI_MODEL` — имя модели; для Ollama с Qwen 2.5: `qwen2.5`;
- `AI_TOOLS_ENABLED` — включает локальный tool calling для математики, физики и химии; по умолчанию `true`;
- `OPENAI_API_KEY` — включает облачный OpenAI и OCR; для локального ИИ через Ollama не требуется;
- `PRACTICE_DB_PATH` — путь к SQLite, по умолчанию `app/data/practice.db` при запуске из каталога `backend`;
- `SCHOOL_SESSION_DAYS` — срок школьной сессии в днях, по умолчанию `30`.

Пароли сохраняются как scrypt-хеши с индивидуальной солью. Браузерная сессия использует `HttpOnly` cookie; на сервере хранится только SHA-256-хеш токена.

## Модель урока

В одном кабинете может быть только один активный урок. Создание или возобновление другого урока завершает предыдущий. Сервер проверяет допустимость предмета для класса и принадлежность каждого кабинета и урока текущей школе.

Операции доски записываются последовательно и имеют клиентский идентификатор для защиты от дублей. Журнал включает штрихи, добавление, изменение и удаление графиков, отмену, повтор и очистку. Старые базы со штрихами автоматически мигрируют на актуальную схему без изменения идентификаторов операций. Чат сохраняет запрос ученика, ответ ассистента и ошибки ответа.

## Запуск

Для полностью локального ИИ установите Ollama и один раз загрузите модель:

```bash
ollama pull qwen2.5
```

Затем скопируйте `.env.example` в `.env`. По умолчанию пример уже настроен на Ollama. OCR изображений требует отдельную мультимодальную модель и с этой настройкой остаётся выключенным.

### Локальные учебные tools

При работе через OpenAI-compatible локальный backend STEM-предметы получают детерминированные функции: решение и упрощение выражений, производные, интегралы, пересечения функций, перевод и проверку размерностей физических единиц, молярную массу и балансировку школьных химических уравнений. Гуманитарным предметам эти функции не передаются.

Чтобы временно отключить tool calling, задайте `AI_TOOLS_ENABLED=false`.

```bash
python -m uvicorn app.main:app --reload --port 8001
```

## Тесты

Из корня проекта:

```bash
.venv-mac/bin/python -m pip install -r backend/requirements-dev.txt
.venv-mac/bin/python -m pytest backend/tests -q
```

Для резервной копии остановите процесс FastAPI и скопируйте `practice.db`. Если копирование выполняется при работающем сервере, используйте штатный механизм SQLite backup, чтобы получить согласованный снимок.
