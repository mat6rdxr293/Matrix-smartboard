# Backend

FastAPI хранит школьные аккаунты, кабинеты, уроки, операции доски и чат с ИИ в SQLite.

## Настройка

Скопируйте `.env.example` в `.env`. Основные параметры:

- `OPENAI_API_KEY` — включает ИИ и OCR;
- `PRACTICE_DB_PATH` — путь к SQLite, по умолчанию `app/data/practice.db` при запуске из каталога `backend`;
- `SCHOOL_SESSION_DAYS` — срок школьной сессии в днях, по умолчанию `30`.

Пароли сохраняются как scrypt-хеши с индивидуальной солью. Браузерная сессия использует `HttpOnly` cookie; на сервере хранится только SHA-256-хеш токена.

## Модель урока

В одном кабинете может быть только один активный урок. Создание или возобновление другого урока завершает предыдущий. Сервер проверяет допустимость предмета для класса и принадлежность каждого кабинета и урока текущей школе.

Операции доски записываются последовательно и имеют клиентский идентификатор для защиты от дублей. Чат сохраняет запрос ученика, ответ ассистента и ошибки ответа.

## Запуск

```bash
python -m uvicorn app.main:app --reload --port 8001
```

## Тесты

Из корня проекта:

```bash
.venv-mac/bin/python -m pip install -r backend/requirements-dev.txt
.venv-mac/bin/python -m pytest backend/tests -q
```

Для резервной копии остановите процесс FastAPI и скопируйте `practice.db`. Если копирование выполняется при работающем сервере, используйте штатный механизм SQLite backup, чтобы получить согласованный снимок.
