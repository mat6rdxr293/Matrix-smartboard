Те же руководства встроены в приложение: кнопка «Справка» на экране выбора класса и в настройках урока, ссылка «Справка для сисадмина» на экранах первой настройки и подключения. Скриншоты сняты в настоящем приложении на каждом языке.

Осы нұсқаулықтар қолданбаға да енгізілген: сыныпты таңдау экранындағы және сабақ баптауларындағы «Анықтама» батырмасы, алғашқы баптау мен қосылу экрандарындағы «Жүйелік әкімшіге арналған анықтама» сілтемесі.

The same guides are built into the app: the "Help" button on the grade screen and in lesson settings, and the "Help for IT admins" link on the first-setup and connection screens.

## Как устроены файлы

- `<язык>/teacher.md`, `<язык>/admin.md` — тексты; `<язык>/images/` — скриншоты в интерфейсе на этом языке.
- Номера разделов во всех языках одинаковые: приложение открывает справку на разделе по номеру.
- Тест `frontend/src/app/help/markdown.test.ts` проверяет, что у каждого руководства есть все картинки, все ссылки ведут на существующие разделы, а нумерация совпадает с русской.
