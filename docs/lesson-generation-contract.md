# Контракт генерации урока v1.0

Этот контракт относится только к материалам, которые создаёт модель для нового урока. Он не меняет формат старых слайдов, импортированных PPTX и ручного редактора.

## Холст

Размер каждого слайда: 960×540 px. Все элементы должны находиться внутри безопасной области с отступом не меньше 35 px от каждого края.

## Слои и пересечения

`elements` одновременно задаёт содержимое слайда и порядок слоёв. Первый элемент массива рисуется ниже, последний — выше.

`text` и `image` не должны пересекаться друг с другом. `shape` разрешено использовать как подложку, карточку, рамку или декоративный фон. Поэтому `shape` может пересекаться с `text` и `image`, но в таком случае должен находиться раньше них в массиве `elements`.

Пересечение `shape` с `shape` разрешено.

## Формулы

Во всех видимых текстовых полях используется обычный Unicode-текст. LaTeX запрещён.

Правильно:

- `Φ = B·S·cos α`
- `F = ma`
- `a = F / m`
- `v² = v₀² + 2as`
- `ω = 2π / T`

Неправильно:

- `$\Phi = BS\cos\alpha$`
- `\frac{F}{m}`
- `v^2`

Правило действует для текста слайдов, вопросов, вариантов ответа, ответов и решений.

## Тема

`theme` задаёт стандартные цвета и шрифт презентации. Указанный непосредственно у элемента стиль имеет приоритет. Если у `text` отсутствуют `color` или `fontFamily`, используются `theme.textColor` и `theme.fontFamily`.

Валидатор не требует, чтобы каждый цвет элемента совпадал с палитрой темы. Дополнительные цвета разрешены, но модель должна использовать тему как основную палитру.

В v1 фон однотонный. Отдельных примитивов `card`, `formulaBlock`, `hero` и подобных нет: карточка создаётся обычным `shape`.

## Поля элементов

### text

Обязательные: `id`, `type`, `x`, `y`, `width`, `height`, `text`, `fontSize`.

Необязательные: `color`, `fontFamily`, `fontWeight`, `align`, `rotation`.

`rotation` по умолчанию равен `0`. Если `color` или `fontFamily` не указаны, они наследуются из темы.

### shape

Обязательные: `id`, `type`, `shape`, `x`, `y`, `width`, `height`, `fillColor`.

Необязательные: `strokeColor`, `strokeWidth`, `cornerRadius`, `rotation`.

Если `strokeColor` отсутствует, рамка не рисуется. `rotation` по умолчанию равен `0`.

### image

Обязательные: `id`, `type`, `x`, `y`, `width`, `height`, `page`, `image_index`.

`image_index` обязателен как поле, но его значение может быть `null`. Необязательное поле: `rotation`.

`page` — физический номер страницы PDF, начиная с `1`. Он не связан с номером, напечатанным в учебнике. Обложка и оглавление считаются обычными страницами PDF.

`image_index` — индекс найденного изображения внутри этой PDF-страницы, начиная с `0`. Если модель не уверена, какое изображение использовать, она передаёт `null`.

Бэкенд не должен заменять `null` случайной картинкой.

## Задания

Каждое задание обязательно имеет уникальный строковый `id`.

### test

Обязательные поля: `id`, `type`, `question`, `options`, `answer`.

`answer` должен дословно совпадать с одним из элементов `options`.

### calc

Обязательные поля: `id`, `type`, `question`, `answer`, `solution`.

`solution` содержит короткий ход решения, достаточный для проверки ответа. Формулы в нём также записываются Unicode-текстом.

```json
{
  "contractVersion": "1.0",
  "theme": {
    "backgroundColor": "#F7F8FA",
    "primaryColor": "#2563EB",
    "textColor": "#111827",
    "mutedTextColor": "#6B7280",
    "fontFamily": "Aptos"
  },
  "slides": [
    {
      "id": "slide_1",
      "title": "Второй закон Ньютона",
      "elements": [
        {
          "id": "card",
          "type": "shape",
          "shape": "round",
          "x": 45,
          "y": 55,
          "width": 870,
          "height": 420,
          "fillColor": "#FFFFFF"
        },
        {
          "id": "formula",
          "type": "text",
          "x": 80,
          "y": 90,
          "width": 300,
          "height": 70,
          "text": "F = ma",
          "fontSize": 36
        },
        {
          "id": "book_image",
          "type": "image",
          "x": 520,
          "y": 90,
          "width": 330,
          "height": 300,
          "page": 14,
          "image_index": 0
        }
      ]
    }
  ],
  "tasks": [
    {
      "id": "task_1",
      "type": "test",
      "question": "Какая формула выражает второй закон Ньютона?",

      "answer": "F = ma"
    },
    {
      "id": "task_2",
      "type": "calc",

      "solution": "a = F / m = 10 / 2 = 5 м/с²"
    }
  ]
}
```

## Бэкенд

`GET /api/lesson-generation/contract` возвращает текущую версию правил и JSON Schema.

`POST /api/lesson-generation/validate` принимает JSON модели и отклоняет результат, если нарушены поля, безопасная область, порядок слоёв, пересечения, правила формул или структура заданий.
