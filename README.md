# Школьная интерактивная доска

Приложение для уроков с интерактивной доской, заданиями, презентациями и ИИ-ассистентом. Одна школа регистрирует общий аккаунт, а каждая доска привязывается к своему кабинету. У кабинетов независимые истории уроков.

## Возможности

- самостоятельная регистрация школы по названию и паролю;
- выбор существующего кабинета или создание нового при первой настройке доски;
- отдельные шаги выбора класса и предмета;
- предметы с учётом школьной программы Казахстана;
- восстановление незавершённого урока после обновления страницы;
- архив уроков каждого кабинета;
- сохранение операций доски `add`, `undo`, `redo`, `clear` и переписки с ИИ.

## Предметы по классам

- 1–2 классы: математика, естествознание, казахский и русский языки;
- 3–6 классы: те же предметы и английский язык;
- 7–11 классы: алгебра, геометрия, физика, химия, биология, география, казахский, русский и английский языки.

Матрица составлена по типовым учебным программам и учебному плану Казахстана: [приказ об учебных программах](https://old.adilet.zan.kz/rus/docs/V2200029767), [перечень программ 1–11 классов](https://www.gov.kz/memleket/entities/kostanai-bilim/documents/details/533222), [типовые учебные планы](https://www.adilet.zan.kz/rus/docs/V2200030654).

## Запуск

### macOS

```bash
chmod +x scripts/dev.sh
./scripts/dev.sh
```

Откройте `http://localhost:5174`. Скрипт запускает FastAPI на порту `8001` и Vite на порту `5174`.

### Windows

```powershell
scripts/dev.ps1
```

## Проверка

```bash
chmod +x scripts/test.sh
./scripts/test.sh
```

В Windows используйте `scripts/test.ps1`.

## Данные

По умолчанию школы, кабинеты и уроки находятся в `backend/app/data/practice.db`. Путь можно изменить через `PRACTICE_DB_PATH`. Перед переносом или резервным копированием остановите сервер и скопируйте файл базы данных.

Секреты задаются в `backend/.env`; пример находится в `backend/.env.example`. Файлы базы, окружения, сборки, медиа и секреты исключены из Git.

## Структура

- `backend/` — FastAPI, SQLite, алгоритмы и интеграция ИИ;
- `frontend/` — React, Vite и Tailwind CSS;
- `scripts/` — команды запуска, сборки и проверки;
- `docs/` — спецификация и план реализации.
