# Matrix Smartboard — ML

ИИ-ассистент учителя для интерактивной доски: офлайн-модель (Qwen3.5-4B → GGUF Q4) и обработка
учебников 9–11 классов (kk/ru/en). Контекст и команды — в `CLAUDE.md`, подробные отчёты — в `REPORT.md`.

**Сценарий:** учитель один раз загружает PDF учебника → доска его обрабатывает (~20 мин) →
учитель выбирает параграф → ИИ генерирует задания и текст для шаблонной презентации.

## Апдейты

Журнал автономной работы: время, что сделано, что получилось.

### Апдейт 1 — 01:25
Старт автономной сессии (~1 час). План:
1. Распознать все три учебника через Tesseract (быстрый рабочий текст, как было бы на доске).
2. Запустить на GPU распознавание казахской физики моделью со зрением (Qwen3.5-4B) — качественный текст
   с формулами в LaTeX, с возможностью продолжить после остановки. Работа долгая, пусть идёт в фоне.
3. Разметка «параграф ↔ страницы» по распознанному тексту.
4. Прототип `lesson.py`: параграф → задания + слайды (JSON), замер времени на CPU в 4 потока.

Учебники в `textbooks/`: история Казахстана 11 (ru, 165 с.), алгебра ЕМН 11 (ru, 254 с.),
физика ЕМН 11, 1-бөлім (kk, 240 с., пометка «Жоба»). Все три — сканы ~95 dpi с okulyk.kz.
